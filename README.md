# Pixel Craft Season #5
Minecraft Version [1.17 (Fabric Server)](https://meta.fabricmc.net/v2/versions/loader/1.17/0.12.0/1.1.2/server/jar) to [1.18.2 (Fabric Server)](https://meta.fabricmc.net/v2/versions/loader/1.18.2/0.13.3/1.1.2/server/jar)

This season ran from June 11th 2021 to June 8th 2022

You can download the [Starting Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-5/worlds/pixel-craft-season-5-starting-map.zip) or [Ending Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-5/worlds/pixel-craft-season-5-ending-map.zip) to explore if you want.

## Info
Season #5 of Pixel Craft this season we have done some major changes such as using Fabric on the servers backend running the Lithium mod, the Carpet mod, and a few other server side things that are handy. We still have datapack from Vanilla Tweaks and CurseForge, with our own custom datapack thrown in there as well. Shops are getting a bit of a downgrade as were using redstone & the honor system for them this season plus we have a few suprises if you are playing on the server this season.

## Server Configuration
### Gamerules
- `commandBlockOutput = false`
- `spawnRadius = 0`
- `doFireTick = false`
### Server.properties
- `level-type = default`
- `difficulty = hard`
- `enable-command-block = true`
- `view-distance = 10`
- `level-seed = 3066343975226411066`
