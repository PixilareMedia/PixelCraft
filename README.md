# Pixel Craft Season #2
Minecraft Version [1.13.2 (Vanilla Server)](https://piston-data.mojang.com/v1/objects/3737db93722a9e39eeada7c27e7aca28b144ffa7/server.jar)

This season ran from December 23rd 2018 to April 22nd 2019

You can download the [Starting Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-2/worlds/pixel-craft-season-2-starting-map.zip) or [Ending Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-2/worlds/pixel-craft-season-2-ending-map.zip) to explore if you want.

## Info
Season #2 was a good season we had fun and added some more active people while keeping things relatively simple but what happened to the first will happen to the second we lost people to other activities and also didn't have the money to keep it running past the end of April but with the main pov's internet being sucky the videos lasted into the end of May.

## Server Configuration
### Gamerules
- `commandBlockOutput = false`
- `logAdminCommands = false`
- `doFireTick = false`
- `keepInventory = true`
### Server.properties
- `level-type = AMPLIFIED`
- `difficulty = 1`
- `enable-command-block = true`
- `view-distance = 10`
- `level-seed = -301090023`
