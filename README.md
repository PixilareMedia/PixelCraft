# Pixel Craft Season #1
Minecraft Version [1.12.2 (Vanilla Server)](https://piston-data.mojang.com/v1/objects/886945bfb2b978778c3a0288fd7fab09d315b25f/server.jar)

This season ran from December 23rd 2017 to May 23rd 2018

You can download the [Starting Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-1/worlds/pixel-craft-season-1-starting-map.zip) or [Ending Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-1/worlds/pixel-craft-season-1-ending-map.zip) to explore if you want.

## Info
Season #1 was a complete failure by all regards we lost interest quite quickly and only made 3 videos on the season. Season #1 was supposed to have 8 people but ended up with 4 and only 3 were originally on the whitelist. This season has no support in any way by any one of the pixels.

## Server Configuration
### Gamerules
- `commandBlockOutput = false`
- `logAdminCommands = false`
- `doFireTick = false`
- `keepInventory = true`
### Server.properties
- `spawn-protection = 0`
- `difficulty = 2`
- `enable-command-block = true`
- `view-distance = 16`
