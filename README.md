# Pixel Craft Season #4
Minecraft Version [1.16.1 (Paper Server)](https://fill-data.papermc.io/v1/objects/639905d3d9a74f64a3ac34dc86bfd8e340f30b861675a74359c2714a4258222f/paper-1.16.1-12.jar) to [1.16.5 (Paper Server)](https://fill-data.papermc.io/v1/objects/269aa74cba42effd8c18ff9c9c7df225f85377f8b9428bafc9ffae2116295dcd/paper-1.16.5-744.jar)

This season ran from June 29th 2020 to June 5th 2021

You can download the [Starting Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-4/worlds/pixel-craft-season-4-starting-map.zip) or [Ending Map](https://cdn.roebuck.dev/user/pixilare-media/pixel-series/pixel-craft/season-4/worlds/pixel-craft-season-4-ending-map.zip) to explore if you want.

## Info
Season #4 of Pixel Craft, this season we have gone back to the roots a bit better that before. As now we only have things that help improve the vanilla gameplay so one play sleep, and a few others from vanilla tweaks. Plus a few plugins to link the game chat to our discord and handle the player shops.

## Server Configuration
### Gamerules
- `commandBlockOutput = false`
- `spawnRadius = 0`
- `doFireTick = false`
### Server.properties
- `level-type = default`
- `difficulty = hard`
- `enable-command-block = true`
- `view-distance = 10`
- `level-seed = -330726833748393262`
